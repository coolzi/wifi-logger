# Wi-Fi Logger

[English](README.md)

Wi-Fi Logger записывает параметры текущего Wi-Fi-подключения на Mac. На графике видны уровень сигнала, шум и SNR. Приложение отмечает обрывы, восстановления связи, изменения канала и смену точки доступа. Нажмите на точку графика, чтобы посмотреть замер в выбранный момент.

- **Замеры Wi-Fi** обновляются примерно каждые 250 мс.
- **Снимки модуляции** показывают доступные данные MCS, тип модуляции, кодовую скорость, скорость радиосоединения и число пространственных потоков. macOS возвращает эти данные отдельными запросами.
- **Сохранить CSV** выгружает все замеры или все снимки модуляции в отдельные файлы. **Файл → Импорт имён точек доступа…** позволяет загрузить имена для BSSID из CSV.

## Сборка и запуск

Нужны macOS 14 или новее и Swift 6. Для разработки на платформах Apple подходит Xcode. Swift Package использует системные фреймворки Apple. [Установка Swift на macOS](https://www.swift.org/install/macos/)

```sh
make
open .build/WiFiLoggerGUI.app
```

Нажмите **Начать запись**. В меню **Справка** описаны навигация по графику, колонки CSV и формат справочника точек доступа. Для Wi-Fi Logger можно выбрать русский или английский в **Системных настройках → Основные → Язык и регион → Приложения**. После смены языка откройте приложение заново. [Инструкция Apple](https://support.apple.com/guide/mac-help/change-the-system-language-mh26684/mac)

Консольная команда печатает примерно один замер в секунду. Для остановки нажмите Ctrl+C.

```sh
./.build/WiFiLogger.app/Contents/MacOS/wifi-logger
```

[Сборка и проверки](BUILD.md) описывают команды для тестов, параметры Command Line Tools и локальный установщик для Apple Silicon.

## Данные и разрешения

Запись хранится в памяти. CSV можно сохранить во время записи. В файл попадут данные, накопленные к моменту подтверждения сохранения. Чтобы сохранить всю сессию, поставьте запись на паузу и сохраните каждый доступный CSV до закрытия окна записи или начала новой сессии. Импортированный справочник точек доступа хранится в Application Support пользователя и доступен после перезапуска.

macOS может запросить доступ к геолокации для чтения имени сети (SSID) и адреса точки доступа (BSSID). В окне для этого есть кнопка **Разрешить**, когда запрос доступен. Для запроса из терминала запустите команду с `--request-location`. В выгрузки и вывод терминала могут попасть SSID, BSSID и время замеров. Проверьте содержимое перед отправкой файла или лога.

Показанная скорость передачи относится к радиосоединению Wi-Fi. Число пространственных потоков (NSS) зависит от недокументированного API CoreWLAN. Его читает отдельный короткоживущий процесс. Если показание недоступно, запись остальных параметров продолжается.

## Как помочь проекту

В описании ошибки укажите версии macOS и Swift, шаги воспроизведения и ожидаемый результат. Используйте синтетические SSID и BSSID в примерах и тестах. Перед отправкой изменений выполните [проверки](BUILD.md).
